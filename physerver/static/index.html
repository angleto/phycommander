BTNFront buttons + LEDs — 3 illuminated pushbuttons (right side)
PosFunctionWiring
TopArduino Due ResetButton → Due RESET pin (POWER header). LED anode → Due +3.3V through 220Ω, LED cathode → GND. Lit = Arduino powered (does not indicate firmware health)
MidPC ResetButton → motherboard reset header (front-panel FPRST). LED tied to PWR_OK / +3.3V_SB from PSU (lit = host booted)
BotMain Power ON/OFFButton → motherboard PWRBTN header (ATX soft-power). LED tied to +12V rail (lit = PSU on)
+12VFront banana jacks — 4 jacks (2 left + 2 right), +12V distribution from host PSU
